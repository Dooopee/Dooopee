# DOOOPEE / Profile design

Внутренний документ к публичному GitHub-профилю. Не предназначен для рекламы и не заменяет техническую документацию ODD PRACTIC.

## 1. Позиционирование

**Текущий фокус:** ODD PRACTIC — тренировки в Counter-Strike 2, концепция в ранней разработке.

**Второй проект:** NEXEL — независимый лаунчер Minecraft Java Edition для Windows. В README используется существующий публичный скриншот.

ODD PRACTIC находится в приватном репозитории, а публичной сборки пока нет. В профиле допустимо описывать **цели и планируемые направления**. Нельзя приписывать ему готовые режимы, KPI, аналитику и тесты.

## 2. Фирменный знак

Исходник: [assets/odd-mark.svg](../assets/odd-mark.svg)

Вторая редакция — три широкие угловые геометрические формы на чёрном фоне. Это самостоятельный знак, **не мишень, не прицел и не буква D**. В центре нет мелких деталей, которые теряются при уменьшении.

- Основной фон: `#0B0B0B`
- Знак: `#F5F5F5`
- Формат: квадрат с большими внешними полями; рассчитан на круговое кадрирование GitHub.
- Использовать статический вариант для аватара. Не добавлять анимацию на аватар.
- Не использовать тени, свечение, стеклянные градиенты или псевдо-3D-объём.

### Публикация аватара

Экспортировать SVG в PNG 1024×1024 без изменения геометрии, затем открыть **GitHub → Settings → Public profile → Profile picture**. Публикация аватара аккаунта — отдельное действие, PR с README его не меняет.

## 3. Layout

- Hero: [desktop](../assets/odd-hero.svg) и [mobile](../assets/odd-hero-mobile.svg). Один и тот же знак; разная композиция.
- Метод: [desktop](../assets/odd-method.svg) и [mobile](../assets/odd-method-mobile.svg). Наглядная схема, а не фальшивый интерфейс.
- NEXEL: существующий [публичный снимок](../assets/nexel-home.webp) интерфейса.
- Стандартные заголовки GitHub, нормальная ширина Markdown, ясные ссылки, осмысленные раскрывающиеся `<details>`.
- Без устаревших блоков с искусственными GitHub-метриками, сервисными badges и заблокированными ссылками.

## 4. Motion specification

| Элемент | Поведение | Допущение |
| :--- | :--- | :--- |
| Заголовок hero | Конечное плавное появление | Только декоративно |
| Фирменный знак | Короткое появление без резких поворотов | Статический знак остаётся читаемым |
| Точки и направляющие | Очень медленная смена прозрачности | Никогда не заменяет содержимое |
| Линия тренировочного цикла | Плавное движение вдоль фиксированного пути | Схема читается и без движения |
| Reduced motion | Отключает все CSS-анимации | Обязательное условие |

Графика должна работать как статичная иллюстрация при отсутствии поддержки SVG-анимации. В SVG не допускаются JS, обработчики событий, внешние ссылки и `foreignObject`.

## 5. Ограничения GitHub

README нельзя превратить в полноценный SPA: GitHub очищает опасный HTML, не выполняет пользовательский JavaScript и не предоставляет полноценные обработчики кликов. Интерактив реализуется **стандартными ссылками, якорями, таблицами и `<details>`**. Любые декоративные кнопки без действий запрещены.

В светлой теме GitHub у SVG сохраняется собственный тёмный фон, поэтому важен контраст текста внутри баннеров. Границы картинки и Markdown-блоков проверяются независимо.

## 6. Содержание и честность

- Не раскрывать код, ключи, конфигурацию или закрытые скриншоты ODD PRACTIC.
- Не ссылаться из публичного README на приватный репозиторий, показывающий посетителям 404.
- Не создавать ссылки на несуществующие releases, docs, домены или каналы.
- Планы обозначать как планы, факты — только после проверки.
- Любое изменение статуса ODD PRACTIC должно сопровождаться правкой профиля.
- Снимок интерфейса NEXEL сопровождается ссылкой на публичный репозиторий, где его можно проверить.

## 7. Проверка

Автоматическая проверка: `python3 scripts/check_profile.py`. Она валидирует локальные изображения и ссылки, XML SVG, отсутствие опасных конструкций, CSS-баланс и reduced-motion fallback.

Ручной этап перед merge:

1. Проверить визуальное отображение PR на GitHub desktop и mobile.
2. Проверить светлую и тёмную тему.
3. Проверить в системном режиме reduced motion.
4. Оценить читаемость знакa на 32 px и при круговом кадрировании.
5. Открыть все внешние ссылки.
6. Подтвердить, что основной проект не описан как уже выпущенный.

## 8. Настройки аккаунта

**Bio (предложение):** `ODD PRACTIC — тренировки CS2, игровые инструменты и собственные приложения.`

**Pinned repositories:** в закреплённые помещать только доступные извне репозитории. Приватный ODD-PRACTIC нельзя представить публичным pinned repo. Пока его нет в открытом доступе, NEXEL уместен как один из закреплённых проектов.

Изменить аватар аккаунта, bio и закреплённые репозитории этим PR невозможно. Это отдельные настройки профиля GitHub.
