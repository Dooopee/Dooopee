# ODD PRACTIC / Profile system

Лаконичное оформление публичного GitHub-профиля, посвящённое одному закрытому проекту: тренировочному хабу для Counter-Strike 2.

## Identity

- Визуальный язык: монохромная техническая графика, строгие направляющие, контрастная типографика.
- Знак: [`odd-mark.svg`](../assets/odd-mark.svg) — самостоятельная геометрия без буквы D и без формы прицела.
- Цвета: `#090A0D`, `#0C0D10`, `#34373D`, `#A7ABB1`, `#F6F7F8`.
- Аватар: статичный PNG из `odd-mark.svg`, сохранять крупные формы и безопасные поля для круглой обрезки.
- Никаких выдуманных цифр, фальшивых интерфейсов, бессмысленных бейджей и сторонних генераторов статистики.

## README

1. `odd-hero.svg`, `odd-hero-mobile.svg` — титульный экран с собственной геометрией и визуальным сигналом.
2. `odd-method.svg`, `odd-method-mobile.svg` — схема предполагаемого тренировочного процесса.
3. Один абзац о продукте, четыре направления разработки, один рабочий раскрывающийся блок.
4. Данные о приватном проекте — только из публично допустимого описания, без кода и скриншотов закрытых функций.

## Motion

- Короткое появление заголовка, непрерывное движение тонких контурных линий, мягкий проход световой полосы.
- Монохромный контраст; без мерцания, резких вспышек, тремора и звука.
- Анимируется **оформление**, а не факты и не элементы управления.
- При `prefers-reduced-motion: reduce` анимации отключаются. Статичный кадр содержит всю информацию.
- Десктопная и мобильная композиции поддерживаются отдельно.

## Interactivity

GitHub README не является исполняемым веб-приложением. Работают ссылки-якоря и раскрытие `<details>`; не работают JS-кнопки и пользовательские обработчики событий. Не выдавать обычные SVG-эффекты за интерактивный UI.

## Account settings

README не меняет левую карточку GitHub: аватар, Bio, website и закреплённые репозитории. Их настройка требует возможностей редактирования профиля аккаунта, а не доступа к репозиторию.

Предлагаемое Bio: `Building ODD PRACTIC — CS2 training hub.`

Для поля website не указывать адрес, которого у проекта нет. Закрытый репозиторий невозможно показать публичным закреплённым проектом.

## Verification

Запуск: `python3 scripts/check_profile.py` — XML, локальные ссылки, якоря, SVG-безопасность, CSS, reduced motion и отсутствие упоминаний устаревших продуктов в видимых материалах.

Перед завершением визуальной приёмки проверить реальные страницы GitHub на десктопе и телефоне, обе темы и reduced motion. Прохождение статических проверок не равно подтверждённому браузерному просмотру.
